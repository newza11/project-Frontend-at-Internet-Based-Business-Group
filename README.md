# project-Frontend-at-Internet-Based-Business-Group

## User Directory

Single Page Application สำหรับจัดการข้อมูลผู้ใช้ พัฒนาด้วย React, Vite และ Ant Design

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

จากนั้นเปิด URL ที่ Vite แสดงใน Terminal (ปกติคือ `http://localhost:5173`)

## ตรวจ Production Build

```bash
npm run build
npm run preview
```

## Requirements checklist

- [x] ฟอร์มผู้ใช้มี Name, Age และ Nickname
- [x] เพิ่มผู้ใช้ใหม่ได้
- [x] แก้ไขข้อมูลผู้ใช้ภายในแถวตาราง (inline edit) ได้
- [x] ลบผู้ใช้ได้ พร้อมกล่องยืนยัน
- [x] เป็น Single Page Application
- [x] ไม่ใช้ Backend และบันทึกข้อมูลใน Web LocalStorage
- [x] ใช้ ReactJS เป็น Frontend

นอกจากนี้ยังมี validation, การค้นหา, responsive layout และข้อความแจ้งผลการทำงาน
